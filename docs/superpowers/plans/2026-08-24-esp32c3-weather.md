# ESP32-C3 每日天气挂件 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MicroPython 固件：ESP32-C3 + 0.96" OLED 显示南京当前天气（子集中文）。

**Architecture:** 板子直连 Open-Meteo；`weather.py` 解析；`font_cn.py` 仅含用字点阵；`display.py` 混排中文/ASCII；`main.py` 循环刷新。

**Tech Stack:** MicroPython (ESP32-C3), SSD1306 I2C, Open-Meteo HTTPS, 主机 Pillow 生成字库

## Global Constraints

- 凭据只进 `secrets.py`，不入库
- v1 无深睡眠、无完整字库、不接 Orchestra
- I2C 引脚可配置，默认常见 C3 OLED 板值并可在 README 说明如何改
