# Stage C5.5: 提交前注水 [Strategist]

**Gate:** QC5.5 (CONDITIONAL — only activates after C5X user confirmation)
**Goal:** Anti-AI-detection watermarking and content padding for submission-ready document
**Needs Composers:** [de-ai-detect (inverse — anti-AI-detection watermarking)]

## Decisions

### Axis Routing

#### Hidden Branch Activation
- **Entry condition:** Only triggered after user confirms in C5X (C5 strategist hidden trigger)
- If C5X was not triggered or user declined → this strategist is never invoked
- Mark meta flag `watermarking_activated: true` on entry

#### Intensity Selection
- STOP-AND-ASK: Select watermark intensity level:
  - `light`: minimal changes, ~10% paragraphs modified
  - `medium`: moderate, ~25% paragraphs modified (default if unspecified)
  - `heavy`: aggressive, ~40% paragraphs modified
  - `ultra`: extreme restructuring, ~60% paragraphs modified
- If user does not specify → default to `medium`

#### LLM Coverage Mode
- **AIGC target mode:** If `meta.json` contains `aigc_target_indices`:
  - All matching paragraphs receive 100% LLM-based rewrite
  - Non-target paragraphs: rule-layer only (no LLM cost)
- **Full-document mode:** (no aigc_target_indices):
  - Only heavy/ultra intensity uses full-document LLM passes
  - light/medium non-target: skip LLM entirely, rule-layer only
  - Probability-based paragraph selection at the chosen intensity

#### Meta Check
- Check if `draft_rule_inflated.meta.json` exists in the output directory
- If yes → AIGC target mode: read `aigc_target_indices` from meta
- If no → full-document mode

#### Paragraph Selection
- **Target mode:** N = len(aigc_target_indices) — all targets are rewritten
- **Full-document mode:** N = M (where M = total_paragraphs * intensity_pct)
  - Probabilistic selection weighted by: paragraph length, AI-tone score, position

#### is_well_formed Guard
- For each LLM-rewritten paragraph:
  - Run `is_well_formed` check: semantic preservation, no hallucinated facts, grammatical correctness
  - If guard passes → replace original paragraph with rewritten version
  - If guard fails → fall back to rule-layer output (synonym substitution, sentence restructuring without LLM)
  - Tag fallback paragraphs with `[RULE-LAYER-FALLBACK]`

#### Error Tolerance
- **Single agent failure:** If >30% of paragraph rewrites fail for one agent:
  - STOP-AND-ASK: report failure rate, offer retry or continue with partial results
- **is_well_formed intercept >20%:** If >20% of LLM rewrites fail the guard:
  - Reduce intensity by one level (e.g., heavy → medium) and retry
  - Log `[INTENSITY-REDUCED]: well_formed_intercept_{pct}%`

### Composer Sequence
1. **composer:** de-ai-detect {mode: inverse_watermark, draft_path: <path>, intensity: <selected>, target_indices: <aigc_targets_or_empty>, language: zh}

## Gate

### QC5.5 Gate Checklist
- [ ] Intensity level confirmed (default: medium)
- [ ] LLM coverage mode determined (target vs. full-document)
- [ ] is_well_formed guard applied to all LLM rewrites
- [ ] Rule-layer fallbacks tagged properly
- [ ] Error tolerance thresholds not exceeded (or user-accepted)
- [ ] Watermarked document ready for submission

### Gate Failure Route
- Failed QC5.5 → route to C5.5A (reconfirm parameters):
  - C5.5A: Re-present intensity selection and mode to user
  - Adjust parameters based on failure reason
  - Re-run watermarking
- 2 consecutive failures → STOP-AND-ASK:
  - Present: "Watermarking has failed twice. Accept current (partial) result or abandon watermarking and use original draft?"
  - Route based on user decision
