## 核心原则：宁缺毋滥

De-AI 编辑的正确性阈值：如果段落已经读起来像合格的人类学术写作，不要为了降低 De-AI 分数而强行修改。过度修改会引入新问题——破坏信息流、删除有助于理解的连接词、产生不自然的短句。

**以下情况不修改：** 无 D1-D20 维度标记、句长有自然变化、段落结构有变化、无模板化结尾句。

**输出正面确认：** 文本通过时明确声明："本节读起来是人类写的中文学术文本。无需 De-AI 修改。"不要为了满足修改配额而制造边缘修改。如果60秒检查零标记，输出通过确认并停止迭代。

## 高频表面标记速查

### D1: 连接词模板化
立即删除或替换：基于此、此外、值得注意的是、然而、与此同时、总的来说、首先—其次—最后（机械排列）。

### D2: 动词名词化（AI 最典型特征）
进行了分析 → 分析了 | 进行了研究 → 研究了 | 开展了调查 → 调查了 | 实施了优化 → 优化了 | 加以说明 → 说明

### D3: 冗余介词框架
通过……的方式 → 直接动作 | 在……方面 → 删除 | 从……角度出发 → 直接说明 | 在……过程中 → 删除

### D4: 弱化表达校准
问题不在 hedging（正常学术表达），而在：堆叠弱化词（"可能在一定程度上"）、公式化弱化（全文只用"可能""或许"）。修复：给出具体程度和数字。

### D5: 代词指代模糊
该模型 → 模型名称 | 其性能 → BERT 模型性能 | 这种现象 → 具体描述

### D15: 结果表述词单一（高频 AI 特征）
**相邻段落不得使用同一结果表述词。** 全文"表明"超过 5 次 → 整体替换一轮。
提示 → 反映/支持/可见 | 表明 → 显示/呈现 | 说明 → 反映/指向 | 可能 → 或与…有关/倾向于

## 翻译腔特征（D16-D18，深层鲁棒信号）

### D16: 零主语缺失 / 话题链扁平化

中文是话题-述题语言。AI 中文受英语 SVO 训练影响，每句都强制插入显式主语。

| AI 特征 | 修复 |
|---------|------|
| "本研究收集了数据。本研究对数据进行了清洗。本研究发现……" | "收集数据，经清洗后分析。结果显示……" |
| 每句以"我们""本研究""本文"开头 | 首次声明身份，后续省略主语，以动词衔接 |

### D17: 的-堆叠检测

单个名词短语中出现 ≥3 个"的" → 高度可疑（英语定语从句直译）。

| AI 特征 | 修复 |
|---------|------|
| "对系统性能产生影响的关键的因素的分析" | 拆分为独立分句或动词短语 |
| 嵌套修饰链 | 重构为话题-述题结构 |

### D18: 被-过度使用

"被"频率每 300 字 >1 个 → AI 信号。原生中文使用话题-述题或主动语态，而非被动。

| AI 特征 | 修复 |
|---------|------|
| "数据被收集后，样本被分为两组" | "数据收集完成后，将样本分为两组" |
| "被……所……" 结构 | 替换为"受到"、"获得"、"由"、"经" |

## 章节风险权重

| 章节 | AI 风险 | 权重 |
|------|---------|------|
| 方法 | 低风险 | 0.10 |
| 结果 | 中风险 | 0.20 |
| 引言 | 中高风险 | 0.25 |
| 讨论 | 高风险 | 0.30 |
| 摘要 | 高风险（可见性） | 0.15 |

**速记规则：** 讨论通过但方法未通过 → 可能是人类。方法通过但讨论未通过 → 很可能是 AI。

## 快速修复规则

1. **动词名词化 → 直接动词**："进行了分析" → "分析了"
2. **连接词 → 删除或替换为具体逻辑**："此外" → 内容本身推进
3. **的-堆叠 → 拆分**：一个名词短语不超过 2 个"的"
4. **被-过度 → 话题-述题**：每 300 字 ≤1 个"被"
5. **零主语恢复**：建立话题后，后续句子省略重复主语
6. **结果表述词轮换**：相邻段落使用不同表述词（提示/显示/反映/支持/可见/指向/倾向于）
7. **冗余介词 → 删除**："通过……的方式" → 直接动词
8. **观点模糊 → 明确立场**："有学者认为……也有观点认为……" → 给出判断
9. **连续 300 字无数字/专有名词 → 补充具体数据**
10. **段落长度机械一致 → 混合短/中/长段**

## D20: 渲染性/情感性词汇检测（新增维度）

AI 倾向使用强烈渲染性词汇包装普通发现。这些词本身不错误，但密度过高（每 800 字 >1 个）是 AI 信号。

### 应立即删除或弱化的词汇

| AI 特征 | 问题 | 优化 |
|---------|------|------|
| 毋庸置疑 | 过度论断 | 删除，或改为"现有证据表明" |
| 颠覆性 | 夸大创新 | "改进""拓展"或具体说明改变程度 |
| 深刻 | 空虚强调 | 删除或用具体机制替代 |
| 切中要害 | 空洞修辞 | 删除，直接说明做了什么 |
| 本质 | 哲学化泛化 | 具体说明"关键机制是……"替代 |
| 耦合内聚 | 软件工程词滥用 | 非软件论文删除，改为人话 |
| 重大突破 | 夸大创新 | "进展""改进" |
| 从根本上 | 空洞强调 | 删除或具体说明机制 |
| 极大提升 | 未量化夸张 | 给出具体数字或百分比 |
| 显著地 | 模板化强调 | 给出 p 值、效应量等具体数字 |
| 全面地 | 过度断言 | 删除或说明范围 |
| 系统性地 | 模板化副词 | 删除或改为具体方法描述 |
| 创新性地 | 自封创新 | 让他人判断；描述做了什么 |
| 前所未有 | 几乎是 AI 签名词 | 删除；如非真正前所未有就别用 |

### 模板化结尾句（摘要/结论高危）

| AI 句式 | 修复 |
|---------|------|
| 具有重要的理论意义和实践价值 | 具体说明理论意义是什么，实践价值是什么 |
| 填补了……空白 | 具体说明填补了什么空白，与已有工作的区别 |
| 为……提供了新的思路 | 具体说明什么思路 |
| 对……具有重要的参考价值 | 具体说明对谁有什么参考价值 |

### 检测阈值
- 每 800 字 >1 个渲染词 → 标记
- 摘要/结论中出现 ≥2 个 → 重点修复
- 全文 ≥8 个 → 整体弱化一轮

## D21（二一）：零因果连词缺陷

AI并列罗列时因果连词密度为零，需人工插入。

**检查：** `因此|通过|从而|进而|不仅` 全文计数。若 `因此+从而` 密度 < 1/万字 → 插入因果连词。若 `通过` 密度 < 2/万字 → 方法段加"通过X"。

1. 搜索：`被|进行了|开展了|此外|值得注意的是|基于此|的的|首先.*其次.*最后|毋庸置疑|颠覆性|本质|耦合内聚|重大突破|前所未有|具有重要理论意义|填补了.*空白|为.*提供了新思路|具有重要的参考价值`
