# Cover Letter (Embedded)

**Source:** `cover-letter` v5.1.0 | **Snapshot:** 2026-06-06
**Pipeline usage:** S10 (Submission Prep — 10A. Cover Letter)

## Structure
| Element | Content |
|---------|---------|
| **Hook** (1-2 sentences) | One-sentence finding and why it matters |
| **Gap** (2-3 sentences) | What was unknown before this paper? Cite key prior work |
| **Contribution** (3-4 sentences) | What did you do? What did you find? Be specific |
| **Fit** (2-3 sentences) | Why THIS journal? Reference recent papers in the journal |
| **Declarations** | No conflicts, not under review elsewhere, all authors approved |

## Key Rules
- Never restate the abstract
- Every claim must trace to visible evidence in the manuscript (align-check)
- For Nature/Science/Cell: broad significance framing
- For field journals: technical fit and specialist audience
- Include: suggested reviewers (3-5), opposed reviewers (if any)
- For double-blind: blind version without author names
