# Scientific Slides (Embedded)

**Source:** `scientific-slides` v1.0 | **Snapshot:** 2026-06-06
**Pipeline usage:** T7 — alternative presentation approach (fallback for nature-paper2ppt)

## Core Principles
- **Visually engaging** — compelling visuals, not just bullet points
- **Minimal text** — bullet points as prompts, you provide explanation verbally
- **Professional design** — modern color schemes, visual hierarchy, white space
- **Story-driven** — clear narrative arc, not data dump

## Standard Slide Structure
| Section | Slides | Duration |
|---------|--------|----------|
| Title | 1 | 30s |
| Outline | 1 | 30s |
| Background | 2-3 | 2-3 min |
| Methods | 1-2 | 2-3 min |
| Results | 3-5 | 5-8 min |
| Discussion | 1-2 | 2-3 min |
| Conclusion | 1 | 1 min |
| Acknowledgments | 1 | 30s |

## Design Checklist
- [ ] Consistent color scheme (max 3 colors + neutral)
- [ ] Readable font size (≥24pt body, ≥36pt title)
- [ ] High-contrast text/background
- [ ] Figures labeled and sourced
- [ ] Slide numbers
- [ ] No more than 7 lines per slide
- [ ] URL/QR code for sharing
