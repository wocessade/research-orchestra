# Typst Paper (Embedded)

**Source:** `typst-paper` v5.1.0 | **Snapshot:** 2026-06-06
**Pipeline usage:** S4 — Typst writing support (when writingFormat=typst)

## Capabilities
- Compile Typst projects & diagnose CLI issues
- Audit format, bibliography, grammar, argument logic
- BibTeX and Hayagriva bibliography support
- Pseudocode/algorithm-block review
- De-AI editing

## Common Commands
```bash
typst compile main.typ
typst watch main.typ    # continuous preview
typst query main.typ "<heading>"  # extract structure
```
