# 作者核对清单

## 使用说明
每写完一个二级节后，请逐项核对以下清单。全部勾选后告知 AI 进入下一节。

---

## §<section> 核对清单

- [ ] 本节内容准确无误，无事实性错误
- [ ] 本节与前面章节无矛盾，逻辑连贯
- [ ] 术语使用一致（同一概念未用不同词表达）
- [ ] 数据/引用可追溯，引用格式正确
- [ ] 本节长度适中（800-1500 字）
- [ ] 核心论点清晰，支撑充分
- [ ] 无冗余或偏离主题的内容
- [ ] 语言表达流畅，无语法/拼写错误

---

## 操作选择

核对完成后，请选择以下操作之一：

| 操作 | 说明 |
|------|------|
| **通过 (APPROVED)** | 内容无误，进入下一节 |
| **小改 (MINOR_FIX)** | 内容基本可用，指出具体修改点，AI 增量修改 |
| **打回 (REJECT)** | 本节问题较多，选择"完全重写"或"指定修改点" |
