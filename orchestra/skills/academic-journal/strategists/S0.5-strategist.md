# Stage S0.5: Project Sanity Check [Strategist]

**Gate:** Q0.5 (SOFT BLOCK)
**Goal:** Answer feasibility questions before investing weeks of effort.
**Needs Composers:** none

## Decisions

### Axis Routing
Entry route is determined by `passport.negative_results_pathway`:

- **If `passport.negative_results_pathway == "null_result_aware"` (set by D1 or S1):** Use Data-First 2-question variant (section 0.5A-DF). Negative findings are expected; adjust timeline and writing strategy accordingly.
- **Otherwise (standard pathway):** Use Idea-First 3-question variant (section 0.5A-IF) when arriving from S1, or Data-First 2-question variant when arriving from D2.

### Entry Routing
- **Idea-First entry (from S1):** Route through 0.5A-IF (3 questions). Score: 0-1 "No" = proceed; 2+ "No" = SOFT BLOCK, requires written override.
- **Data-First entry (from D2, D2 already passed):** Route through 0.5A-DF (2 questions, question 1 is pre-resolved — data is in hand). Score: 0 "No" = proceed; 1+ "No" = SOFT BLOCK, must return to D2 or write override.

### Scoring Logic
**Idea-First (3 questions):**
- 0 "No" → Proceed
- 1 "No" → Proceed but resolve before Stage 3 (Outline); flag it
- 2+ "No" → SOFT BLOCK. Must: (a) return to S1 and change question, (b) narrow scope (see 0.5D), or (c) document explicit "proceed anyway" justification with advisor/PI sign-off

**Data-First (2 questions):**
- 0 "No" → Proceed normally
- 1+ "No" → SOFT BLOCK. Must: (a) return to D2 and re-evaluate candidate claims, (b) narrow scope (see 0.5D), or (c) document explicit "proceed anyway" justification
- 2 "No" → SOFT BLOCK. Return to D2. Question not viable with current data, timeline, or goals.

### Paper Type → Time Budget Routing
After passing Q0.5, determine paper type and set time budget:

| Paper Type | Timeline | Checkpoint |
|------------|----------|------------|
| Short / Letter | 2-4 weeks | Week 2: Q3 |
| Standard article | 6-8 weeks | Week 4: Q4 |
| Multi-study / Comprehensive | 10-16 weeks | Week 6: Q5 |
| Data paper | 4-6 weeks | Week 3: Q4 |
| Software/tool paper | 6-10 weeks | Week 4: Q4 |
| Benchmark paper | 8-12 weeks | Week 5: Q5 |

**Overrun detection (0.5C):** If checkpoint missed by >50%, trigger scope reduction (0.5D).

### Scope Reduction Options (0.5D)
| Current Scope | Reduced To | What You Keep |
|---------------|------------|---------------|
| Multi-study | Single study + supplementary | Core finding |
| Full causal (mechanism + effect) | Effect paper | Effect size + robustness |
| Comprehensive review | Focused mini-review | Curated insight |

### Negative Results Detection
If user's main finding is negative/null/zero effect → set `passport.negative_results_pathway = "null_result_aware"`. If positive or uncertain → set `passport.negative_results_pathway = "standard"`. Pipeline downstream will adjust writing and reviewer guidance accordingly.

## Gate

### Q0.5 Gate Checklist
- [ ] Questions answered honestly for the correct path (IF: 3 questions; DF: 2 questions)
- [ ] If 0-1 "No" (IF) or 0 "No" (DF): proceed normally
- [ ] If blocked: either change question, change scope, or document explicit justification
- [ ] Time budget set (if proceeding)
- [ ] Scope reduction triggers known

### Gate Failure Route
Q0.5 is SOFT BLOCK.

1. **Idea-First (2+ "No"):** (a) return to S1 to modify question, (b) narrow scope (0.5D), or (c) document explicit "proceed anyway" justification needing advisor/PI sign-off.
2. **Data-First (1+ "No"):** (a) return to D2 to re-evaluate candidate claims, (b) narrow scope, or (c) document explicit "proceed anyway" justification.
3. **If still blocked after two attempts:** STOP-AND-ASK: abandon current direction, or lower standards and proceed with known limitations.
