# Stage S1.5: Design & Validity [Strategist]

**Gate:** Q1.5 (CONDITIONAL BLOCK) — only blocks causal/associational papers.
**Goal:** Lock in research design before reading the literature.
**Needs Composers:** none

## Decisions

### Axis Routing
Routing is determined by `passport.research_question` and paper type classification from S1.

### Applicability Matrix (S1.5, lines 7-12)

| Paper Type / Question Type | S1.5 Pass Level |
|----------------------------|-----------------|
| Causal / Associational | Full pass (1.5A + 1.5B + 1.5C + 1.5D) |
| Descriptive / Comparative | Light pass (1.5A only — design type selection) |
| Pure Literature Review / Theory / Conceptual | Skip entirely → route to S2 |
| Data paper / Software/Tool / Benchmark | Skip entirely → route to S2 |
| Registered Report | Full pass (1.5A-D + 1.5-RR all sections) |

### Downgrade Path (S1.5, lines 51-58)
If causal claim is unsupported by exogenous variation (data already collected, no instrument available):
1. Reclassify from "Causal" to "Associational"
2. Change language: "causes/affects/leads to" → "is associated with/predicts/correlates with"
3. Add limitations paragraph acknowledging no causal support
4. Target journals accepting associational work (Stage 8.5 Route C or B with correlational framing)
5. Pipeline continues normally — this downgrade does NOT block

### Registered Report Path (S1.5-RR, lines 100-186)
- IF paperType = "registered-report" → enter RR sub-pipeline: RR-A (hypothesis specification) → RR-B (methods) → RR-C (analysis plan) → RR-D (deliverables) → RR-E (platform selection) → RR-F (pipeline notes) → RR-G (checklist)
- ELSE → skip RR sections.

### Sub-Step Execution Order (Full Pass)
1.5A (Design Type Selection) → 1.5B (Identification Strategy — causal only) → 1.5C (Statistical Power — empirical only) → 1.5D (Validity Check)

1.5A always runs first. 1.5B is conditional on causal/associational. 1.5C is conditional on empirical papers.

### STOP-AND-ASK Points
- **Downgrade path (line 51-58):** If causal claim lacks exogenous variation and user has no alternative → inform user and offer downgrade. Do not block pipeline.
- **Q1.5 failure (line 198):** If identification strategy cannot be fixed → STOP-AND-ASK: downgrade to associational/descriptive framing (bypasses the gate).

## Gate

### Q1.5 Gate Checklist (Conditional)
- [ ] Design type selected and justified
- [ ] **If causal or associational:** Identification strategy documented (all 5 elements from 1.5B)
- [ ] **If causal:** At least 2 assumption tests planned
- [ ] **If empirical:** Power analysis documented (effect size detectable given N)
- [ ] **If empirical:** Top validity threats rated with mitigation plan
- [ ] **If NOT causal:** Skip this gate — proceed to Stage 2

### Gate Failure Route
Q1.5 is CONDITIONAL BLOCK — blocks causal/associational papers only.

1. **Identification strategy check fails** → return to 1.5B for 5-element identification strategy repair → re-verify gate.
2. **After repair still fails** → STOP-AND-ASK: downgrade to associational/descriptive claim (bypasses gate), or abandon causal claim entirely.
