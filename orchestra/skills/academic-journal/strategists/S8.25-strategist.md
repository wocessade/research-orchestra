# Stage S8.25: Preprint Submission [Strategist]

**Gate:** Q8.25 (ADVISORY) — preprint posted to repository or decision documented to skip. Never blocks.

**Goal:** Post a preprint to establish priority date, solicit community feedback, and increase discoverability.

**Needs Composers:** none

## Decisions

### Paper Type Routing (S8.25, lines 14-39)
Route determines whether preprint typically benefits:

- **Papers that benefit:** Empirical, literature review, data paper, software/tool, benchmark → typically benefit from preprint.
- **Papers that may skip:** Theory, registered report (Stage 1 protocol IS the preprint), course assignment, thesis (already in university repository) → may skip; limited benefit.
- **STOP-AND-ASK:** "Do you want to post a preprint before journal submission?" YES → proceed; NO → document reason, skip to S9.

### Server Selection (S8.25, lines 41-58)
Select repository based on discipline:

| Discipline | Server |
|-----------|--------|
| Physics, CS, Math, Stats, Engineering | arXiv |
| Life sciences | bioRxiv |
| Health sciences (clinical) | medRxiv |
| Multidisciplinary, Springer Nature | Research Square |
| Social sciences, humanities | SSRN |
| Engineering | engrXiv |
| Chemistry | ChemRxiv |

**Three selection criteria:**
1. Does target journal allow preprints? (95%+ do in 2026 — check SHERPA/RoMEO)
2. Does funder mandate a specific repository? (NIH: PubMed Central; Wellcome: Europe PMC)
3. Does the server accept your paper type? (e.g., arXiv requires certain subject areas)

### Format Preparation Decision (S8.25, lines 60-80)
Check journal requirements:
- Some journals require removal of journal-specific formatting before posting.
- Some require embargo period before public release.
- Some require "preprint" inclusion in repository metadata.

### Composer Sequence
None. S8.25 is a user-interaction stage with no composer invocations.

## Gate

### Q8.25 Gate Checklist (Advisory)
- [ ] Preprint decision made (post or documented skip)
- [ ] If posting: server selected with justification
- [ ] If posting: preprint-ready PDF prepared (disclaimer, license, metadata)
- [ ] If posting: preprint submitted and DOI recorded
- [ ] If posting: ORCID updated
- [ ] If posting: co-authors notified
- [ ] If skipping: reason documented (will be visible to user)

### Gate Failure Route
Q8.25 is ADVISORY — never blocks. Failure does not block progression but should be addressed before submission.
