# Stage S8.5: Publication Strategy [Strategist]

**Gate:** Q8.5 (SOFT BLOCK) — publication strategy selected, can proceed with warning if using pre-chosen venue.

**Goal:** Select target journal BEFORE formatting. Formatting before venue selection = rework.

**Needs Composers:** none

## Decisions

### Discipline Routing (S8.5, line 8)
- IF `discipline == "stem"` → load `references/discipline-stem.md`.
- IF CS conferences → skip venue selection entirely (venue chosen before starting).
- IF CS journals → use CCF tier system mapped to domestic A/B/C/D tiers.
- IF CS conferences with `venue == "chinese-conference"` → use CCF Chinese conference tier mapping.

### Route Selection (8.5A-8.5B, lines 17-47)
**Chinese domestic journal?** Skip Route A/B/C system. Load `references/chinese-journal-adapter.md`, use A/B/C/D tier system instead.

**International journals only decision tree:**

```
Can you afford 6+ months of uncertainty?
├── NO -> Route C (Fast Track) or Route B with fastest field journal
└── YES -> Novelty Score >= 4.0? (from S2.5)
    ├── YES -> Scoop Risk high? (from S2.5)
    │   ├── YES -> Route A accelerated (preprint + submit within 2 weeks)
    │   └── NO -> Route A (standard timeline)
    └── NO -> Novelty Score >= 2.5?
        ├── YES -> Route B (Balanced)
        └── NO -> Route C (Fast Track)
```

### Redundancy Strategy (DP28, Mode B x3, lines 11-15)
Journal recommendations use Mode B x3 redundancy:
- 3 agents independently recommend and rank 3-5 target journals.
- Orchestrator compares: 3/3 agreement = high-confidence; 2/3 = candidate; 1 agent only = listed but flagged.

### Journal Style Adaptation (8.5B+, lines 43-51)
Optional enhancement — use when:
- Target journal has a distinctive house style, OR
- Author is new to the journal, OR
- Route A submission where stylistic fit matters.

Skip when: Route C fast-track, OA mega-journals, pre-selected venue with known style, Chinese domestic (use `chinese-journal-adapter.md`).

Style adaptation runs AFTER S7 but may trigger a lightweight S7 re-pass focused on P5 (De-AI) cleanup only.

### Venue Name Generation (8.5C, lines 53-90)
**Existing-Manuscript entry handling:**
IF entry via existing-manuscript (S2.5 bypassed) → skip decision tree. Ask user directly: "What tier are you targeting — top journal, field leading, or specialized?" Extract seed journals from user's most-cited journals, stated targets, or prior publication venues.

**Non-existing-manuscript:**
- Step 1: Extract seed journals from S2.5 competing papers table (Journal column = 3-5 seeds), OR S2D gap analysis (journals appearing 3+ times in cited papers), OR user-named target at S1.
- Step 2: Filter by Route tier (A: CNS-level, B: field top, C: specialized/OA).
- Step 3: Discard objectively wrong fits — scope mismatch, tier mismatch (2+ tiers above realistic target).

Output: 3-5 named journals, ranked.

### Automated Predatory Check (8.5D.5, lines 105-122)
For each candidate venue (3-5 journals), run:
1. Beall's List cache check — ISSN exact match + name Levenshtein distance.
2. Think. Check. Submit. cross-check — 7 red flags via AI agent.
3. OpenAlex Sources API verification — works count, citation count, type check.

Record verdict (PASS/WARN/BLOCK). IF BLOCK → remove from candidate list, replace with next alternative.

### Special Situation Routing (8.5E, lines 126-133)

| Situation | Strategy |
|-----------|----------|
| Career deadline | Speed > Prestige. Route C or fastest Route B. |
| Hot topic, competitors active | Route A accelerated. Preprint immediately. |
| Methods-focused paper | Target methods journals. Method novelty > finding novelty. |
| Null result | Check if journal accepts null results (BMC Research Notes, PLOS ONE, F1000Research, PeerJ). |
| Interdisciplinary paper | Target interdisciplinary journals. Be aware of cross-discipline reviewer gaps. |

### Chinese Journal Routing (8.5G-8.5H, lines 145-165)
- IF target is Chinese domestic journal → read `references/chinese-journal-adapter.md`. Confirm S8.6 will run before S8 formatting.
- IF `venue == "chinese-conference"` → read `references/chinese-conference-adapter.md`. S8.5 mostly skipped (conference chosen before writing). S8.6 skipped. Pipeline condensed. Bypass S8.6 entirely, go S8.5->S8 directly.
