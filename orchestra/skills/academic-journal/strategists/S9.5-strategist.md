# Stage S9.5: Reviewer Attack Drill [Strategist]

**Gate:** Q9.5 (SOFT BLOCK) — reviewer attack drill complete, all "Fix Now" items resolved, top 5 Critical items pass.

**Goal:** Stress-test paper against the two most dangerous reviewer types BEFORE submission.

**Needs Composers:** none

## Decisions

### Parallel Dispatch (9.5, line 8)
Launch both attack personas in parallel (DP14). Merge findings, classify issues, fix Critical items.

### Two Attack Personas (9.5A, lines 11-17)

| Persona | Focus | Method |
|---------|-------|--------|
| The Hostile Reviewer | Reads every claim with suspicion. Finds 5 strongest grounds for rejection. | Dislikes paper, no benefit of doubt, doesn't invent flaws. |
| The Statistician Reviewer | Statistical methods audit. Checks method-question match, assumptions, p-value interpretation, degrees of freedom, conclusion scope. | Finds specific errors, not stylistic complaints. |

### Response Classification (9.5B, lines 19-27)
For every issue found by either persona, classify into one of four responses:

| Response | When to Use | Action |
|----------|-------------|--------|
| Fix Now | Issue is real and fixable | Implement fix immediately. Re-run affected analyses. |
| Acknowledge as Limitation | Real issue, fundamentally can't fix | Add to Limitations section with honest language |
| Pre-emptive Defense | Expected but have counter-argument | Add 1-2 sentences before reviewer finds it |
| Rejected with Reason | Reviewer misunderstood / claim doesn't apply | Prepare justification for response letter |

### Top 5 Fatal Flaws Check (9.5C, lines 29-39)
IF any of the following is flagged by attack drill → fix before submission:

1. Claim/data mismatch — abstract claims more than data supports
2. Method/question mismatch — analysis doesn't answer RQ
3. Ignored confound — obvious alternative explanation not addressed
4. N problem — sample too small for number of tests/parameters
5. Overclaiming causality — causal language for associational design

### Convergence Condition (9.5D, lines 50-55)

After Round 1:
- IF 0 Critical items found -> CONVERGED immediately -> proceed to S10.
- IF Critical items found -> fix, run ONE more round (Round 2 max).

Round 2:
- IF 0 new Critical AND <= 2 new Major -> CONVERGED -> proceed to S10.
- IF new Critical -> fix, acknowledge remainder. Do NOT run Round 3.
- Hard cap: 2 rounds max.

### Composer Sequence
None. S9.5 launches two parallel attack personas via `skills-embedded/peer-review.md` with specific prompt overrides — no composer invocation needed.

## Gate

### Q9.5 Gate Checklist (Soft Block)
- [ ] Hostile reviewer attack completed, issues classified
- [ ] Statistician attack completed, issues classified
- [ ] Merged issue list from both personas saved to `{output_dir}/S9.5_merged_issues.md`
- [ ] All "Fix Now" issues resolved
- [ ] Top 5 fatal flaws all pass
- [ ] Pre-emptive defenses added for the top 2-3 expected reviewer objections
- [ ] Convergence condition met (Round 1: 0 Critical -> immediate; Round 2: no new Critical + <= 2 new Major)

### Gate Failure Route
Q9.5 is SOFT BLOCK — failure does NOT formally block submission.

- IF Critical items remain after round 2 → paper has known weaknesses that a competent reviewer will find. The question is whether to find them now (while fixable) or in peer review (when only response is possible).
- No formal gate failure — warn user and proceed or re-run based on user decision.
