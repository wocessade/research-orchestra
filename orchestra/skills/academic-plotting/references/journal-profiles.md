# Journal profiles (verify against current author guides)

Specs drift — always re-check the venue's live guide before camera-ready.

## Common widths (single / double)

| Profile | Single | Double | Notes |
|---------|--------|--------|-------|
| Nature-family | ~89 mm | ~183 mm | max height ~247 mm |
| Science | ~90 mm / other | ~183 mm | check current |
| Cell | ~85 mm | — | check current |
| IEEE 1-col | ~3.5 in | ~7.16 in | conference dependent |
| ACM | template-defined | | use acmart |

## Fonts and lines

- Sans: Arial/Helvetica preferred for many journals.
- Body/tick text often 5–7 pt at final size for dense Nature-style figures; CS papers may use ~8–10 pt — follow venue.
- Panel labels ~8 pt bold lowercase.
- Line weights ≥ 0.5 pt.

## DPI

| Type | Target |
|------|--------|
| Photos / halftone | ≥300 DPI |
| Line art if raster | often ≥600 DPI |
| Vector line art | PDF/SVG/EPS preferred |

## Color

- RGB for online; CMYK only if required for print.
- Do not claim Nature/Science compliance unless built at profile size and audited.

## Stages

- `draft`: readable, not final size critical
- `revision`: apply profile size
- `final_artwork`: strict profile + QA checklist
