## Rules

- support_type: support / contrast / method / dataset / metric / related.
- verified records bibliographic identity only. support_status: pending / supports / partial / mismatch / unavailable.
- supports requires the original text at locator to support the exact claim, including quantity, direction, population and scope. Record its verbatim source_excerpt; escape table pipes or link to an excerpt file.
- Existing verified-only rows have pending support until checked. Do not invent citation keys or mix style samples with evidence.
