# Command: /verify-math — 数学推导验证

**来源:** Claude-Scholar 的 `/verify-math` 命令

## 用途

对论文中的数学推导进行程序化验证。提取 LaTeX 公式 → 用 SymPy 进行符号推导 → 对比推导步骤是否一致。

## 适用场景

- 论文中包含多步数学推导
- 存在公式转换、符号替换、等式变形
- 需要验证推导逻辑的数学正确性（非打字错误检查）

## 运行流程

```
1. 从论文文本中提取所有 LaTeX 数学环境:
   - $$ ... $$
   - \[ ... \]
   - \begin{equation} ... \end{equation}
   - \begin{align} ... \end{align}

2. 对每个公式:
   a. 解析 LaTeX → SymPy 表达式
   b. 对相邻公式做等式验证：
      - eq(N) → eq(N+1): 变换是否数学有效？
      - 是否有除以零风险？
      - 符号替换是否一致？

3. 输出验证报告:
   - ✅ 推导正确
   - ⚠️ 需要人工检查（符号命名歧义、非标准变换）
   - ❌ 推导错误（请修复）
```

## 依赖

- Python: sympy, latex2sympy2 (用于 LaTeX → SymPy 转换)
- 安装: `pip install sympy latex2sympy2`

## 输出格式

```
── 数学推导验证报告 ──
公式数: 12
已验证: 10 ✅
需检查: 1 ⚠️
  公式 #7 (Eq. 2.15): 符号 Σ 在上下文中使用不一致
推导错误: 1 ❌
  公式 #11 (Eq. 3.8): 从 eq(10) 到 eq(11) 的变换中，
    - 左侧: ∂L/∂w = (2/n)Σ(y_i - w·x_i)(-x_i)
    - 右侧: ∂L/∂w = -(2/n)Σ(y_i - w·x_i)x_i
    - 验证: 正确展开（符号无误）
```

## 局限

- 仅验证符号推导，不验证数值正确性
- 不支持所有 LaTeX 宏包（amsmath 标准宏支持）
- 复杂的非标准符号替换可能需要人工确认
