# CONSORT 2010 Checklist — 随机对照试验报告规范

**来源:** CONSORT Group (http://www.consort-statement.org/)

适用于报告随机对照试验（RCT）的论文。每次条目检查结果为 ✅ / ⚠️ / ❌ / N/A。

| 章节 | 条目 | 描述 | 检查结果 |
|------|------|------|---------|
| **标题与摘要** | 1a | 标题中标识为"随机对照试验" | |
| | 1b | 结构化摘要（背景、方法、结果、结论） | |
| **引言** | 2a | 科学背景和原理说明 | |
| | 2b | 具体目标或假设 | |
| **方法** | 3a | 试验设计描述（如平行设计、析因设计） | |
| | 3b | 试验开始后的重要方法变更及原因 | |
| | 4a | 受试者合格标准 | |
| | 4b | 数据收集的环境和地点 | |
| | 5 | 干预措施（各组详细描述） | |
| | 6a | 预设的主要和次要结局指标 | |
| | 6b | 试验开始后结局指标的变更及原因 | |
| | 7a | 样本量如何确定 | |
| | 7b | 中期分析和停止规则（如适用） | |
| **随机化** | 8a | 随机序列生成方法 | |
| | 8b | 随机化类型和限制（如区组、分层） | |
| | 9 | 分配隐藏机制 | |
| | 10 | 实施（谁生成序列、谁登记受试者、谁分配） | |
| | 11a | 是否对谁设盲（受试者、干预实施者、结局评估者） | |
| | 11b | 干预措施的相似性描述（如设盲） | |
| | 12a | 比较组的统计方法 | |
| | 12b | 附加分析方法（亚组分析、校正分析） | |
| **结果** | 13a | 受试者流程（随机分配、接受干预、完成研究、分析的人数） | |
| | 13b | 招募期间和随访时间 | |
| | 14a | 基线人口学和临床特征 | |
| | 14b | 各组纳入分析的人数 | |
| | 15 | 主要和次要结局结果（各组估计值+精确度） | |
| | 16 | 辅助分析（如亚组分析、校正分析） | |
| | 17a | 各组的不良事件或危害 | |
| | 17b | 对危害的详细说明（若有） | |
| **讨论** | 18 | 局限性（偏倚、不精确性、多重分析） | |
| | 19 | 结果的可推广性 | |
| | 20 | 结果解释（考虑目标、假设、潜在偏倚） | |
| **其他** | 21 | 试验注册号和注册名称 | |
| | 22 | 完整的研究方案获取途径 | |
| | 23 | 资助来源和作用 | |

## 使用方式

论文写完后，对照此表逐项检查。所有条目应为 ✅ 或 N/A。存在 ⚠️ 或 ❌ 的条目需修改论文后重新检查。

集成到 evaluate: 当 `discipline=health/medicine` 且 `paperType=empirical` 时，自动激活 standards_compliance agent 加载此 checklist。
