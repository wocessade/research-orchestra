# PRISMA 2020 Checklist — 系统综述和 Meta 分析报告规范

**来源:** PRISMA Group (http://www.prisma-statement.org/)

适用于报告系统综述和 Meta 分析的论文。

| 章节 | 条目 | 描述 | 检查结果 |
|------|------|------|---------|
| **标题** | 1 | 标题标识为系统综述/Meta 分析 | |
| **摘要** | 2 | 结构化摘要（背景、方法、结果、讨论、注册信息） | |
| **引言** | 3 | 理论基础：已知和未知 | |
| | 4 | 目标：PICO 框架 | |
| **方法** | 5 | 纳排标准（PICO、研究设计、时间、语言） | |
| | 6 | 数据库名称（如 Medline, Embase, Web of Science） | |
| | 7 | 检索策略（至少一个数据库的完整检索式） | |
| | 8 | 筛选过程（至少 2 人独立筛选） | |
| | 9 | 数据提取过程（至少 2 人独立提取 + 冲突解决） | |
| | 10a | 提取的数据项列表 | |
| | 10b | 结局指标的优先层级 | |
| | 11 | 偏倚风险评估工具（如 RoB 2, ROBINS-I） | |
| | 12 | 效应量指标（如 RR, OR, MD, SMD） | |
| | 13a | 合成方法（异质性处理、效应模型选择） | |
| | 13b | 异质性评估方法（I², tau², Q 检验） | |
| | 13c | 发表偏倚评估方法（漏斗图、Egger 检验） | |
| | 13d | 额外分析（亚组、Meta 回归、敏感性） | |
| | 14 | 可信度评估（GRADE 或类似工具） | |
| **结果** | 15a | PRISMA 流程图（筛选各阶段人数） | |
| | 15b | 筛选排除原因 | |
| | 16 | 纳入研究特征表 | |
| | 17 | 纳入研究偏倚风险评估结果 | |
| | 18 | 单个研究结果（每个研究的效应量+精确度） | |
| | 19a | 合成结果（合并效应量+异质性） | |
| | 19b | 所有已合成结局的数据 | |

| | 21 | 额外分析结果（亚组、敏感性） | |
| | 22 | 证据确信度（GRADE 结果） | |
| **讨论** | 23 | 主要发现总结 | |
| | 24 | 局限性（研究层面+综述层面） | |
| | 25 | 结果解释（考虑证据确信度） | |
| **其他** | 26a | 研究注册号和注册名称（如 PROSPERO） | |
| | 26b | 综述方案的获取途径 | |
| | 27 | 资助来源 | |
| | 28 | 利益冲突声明 | |
| | 29 | 数据、代码和其他材料的可用性 | |

## 使用方式

适用于系统综述/Meta 分析类论文。需要提供 PRISMA 流程图展示筛选过程。

集成: 当 `paperType=literature-review` 时，standards_compliance agent 加载此 checklist。
