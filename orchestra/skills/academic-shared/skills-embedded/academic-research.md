# Academic Research (Embedded)

**Source:** `academic-research` v2.2.0 | **Snapshot:** 2026-06-06
**Pipeline usage:** S8 (Compile), S10 (Pre-Submission Audit)

## Pre-Submission Checklist
- [ ] Author list complete, affiliations correct, corresponding author marked
- [ ] All fonts embedded in PDF (check with `pdffonts`)
- [ ] PDF metadata correct (title, authors, keywords)
- [ ] File naming follows journal convention
- [ ] Word/page count within venue limits
- [ ] All figures meet resolution requirements (300 DPI min for raster)
- [ ] Conflict of interest statement included
- [ ] Funding acknowledgments complete with grant numbers
- [ ] Ethics approval statement included (if applicable)
- [ ] Data deposited in repository with accession number/DOI
- [ ] Preprint status declared in cover letter (if applicable)
- [ ] Blind manuscript for double-blind review (if required)
- [ ] CRediT author contribution statement
- [ ] ORCID iD for corresponding author
- [ ] Raw manuscript files backed up (.tex, .bib, figures/)

## Cross-Disciplinary Notes
- **CS/Engineering:** anonymous repo link, README, pinned dependencies
- **Biomedical:** clinical trial registration number, protocol preprint
- **Social Sciences:** pre-registration, survey instruments as supplementary
