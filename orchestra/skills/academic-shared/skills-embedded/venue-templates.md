# Venue Templates (Embedded)

**Source:** `venue-templates` v1.0 | **Snapshot:** 2026-06-06
**Pipeline usage:** S6 (pre-formatting), S8.5 (venue formatting)

## Supported Venues
| Category | Venues |
|----------|--------|
| General Science | Nature, Science, Cell, PNAS |
| Multidisciplinary | Nature Communications, Scientific Reports, PLOS ONE |
| CS/AI | NeurIPS, ICML, CVPR, ACL, AAAI, ACM conferences |
| Engineering | IEEE Transactions, IEEE conferences |
| Biomedical | JAMA, BMJ, The Lancet, Cell Press journals |
| Chinese | 中国科学, 科学通报, 各高校学报 |

## Template Access
- Nature: `https://www.nature.com/nature/authors`
- Science: `https://www.science.org/content/page/science-instructions-authors`
- IEEE: `https://template-selector.ieee.org/`
- ACM: `https://www.acm.org/publications/proceedings-template`
- Springer LNCS: `https://www.springer.com/gp/computer-science/lncs/conference-proceedings-guidelines`

## Key Formatting Checks
- Page/word limits
- Reference format (numbered vs author-year)
- Figure resolution (300 DPI minimum for raster)
- Font embedding in PDF
- Section structure required
- Abstract word limit
