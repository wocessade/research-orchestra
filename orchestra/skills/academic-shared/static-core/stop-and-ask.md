# Stop and Ask Protocol

See [shared execution policy](../references/execution-policy.md) for authorization and routine autonomy.

Ask only when missing information changes the scientific conclusion, task scope, or an explicit human gate:

| Situation | Required decision |
|-----------|-------------------|
| Ambiguous data semantics, missingness, outliers or raw-data processing | Clarify interpretation before changing analysis or excluding observations. |
| Research question, contribution, success criteria or target venue change | Present evidence and tradeoffs; preserve work that remains valid. |
| Unresolved citation after available verification | Show the candidate or missing source; leave the claim pending. |
| Concrete ethics/IRB uncertainty affecting the requested study | Identify the specific unresolved requirement. |
| Unavailable source data or figure-editing capability | Explain the exact missing input after checking available tools. |
| Conflicting advisor feedback or unchanged issues after 3+ review rounds | Summarize unresolved choices before repeating work. |

Implement clear, authorized advisor corrections without a second approval. Do not pause merely because no named skill exists, a reviewer finds an error, or a routine choice has multiple valid options. Continue independent work while a required answer is pending.

Use the current environment's user-input mechanism. Tool execution permissions do not establish research decisions or external-action authorization.

For direction changes, record completed outputs, identify affected stages, and resume at the earliest affected stage. Do not restart unaffected work.
