# Emergency Shortcut — Minimal Viable Thesis

Use only when deadline is imminent. Skip polish depth but never skip verification.

## Minimal Viable Thesis (thesis, deadline tomorrow)

```
1. T1 — topic + one-line research question. 任务书 simplified (title + timeline only).
   开题报告 shortened (background 1 page + methodology sketch + 5-8 refs).
   Skip formal 任务书/开题报告 if university doesn't require them.
2. T1.5 (if hasData=true) — data sniff only (T1.5A). Skip full descriptive EDA (T1.5B).
3. T2 — 1 agent search (mix of English + Chinese). Target: degree minimum refs (bachelor 15+ / master 20+).
   Skip thematic grouping depth — basic categorization is enough.
4. T3 — methodology chapter essentials only. Research design type + data/sources + analysis method outline.
   Skip detailed validity threats and instrument validation.
5. T4 — core chapters only (skip 绪论 and 文献综述 prose). Write results/analysis chapters.
   Skip polishing: 封面, 致谢, 声明页 can be generated as templates without careful review.
   Minimum word count check: skip — just ensure core chapters are substantive.
6. T5-Lite — 1 review agent (T5C format + basic content). Fatal-only check.
7. T6 — 1 round fix then deliver. No convergence loop.
8. T7 — PPT only (T7B). Skip defense script (T7C) and Q&A preparation (T7D).
   Minimal PPT: 8+ slides (title, outline, background, methodology, key results, conclusion, acknowledgements, Q&A).
```

**Skipped in MVP:** T2 thematic analysis depth, T3 full methodology documentation, T4 front/back matter polishing, T5 full 9-10 agent review, T6 convergence loop, T7C (script), T7D (Q&A).

**Never skipped even in MVP:** T1 topic definition, T2 minimum reference count, T3 methodology chapter (abbreviated), T4 core chapters, T5-Lite content check, T7B defense PPT.
