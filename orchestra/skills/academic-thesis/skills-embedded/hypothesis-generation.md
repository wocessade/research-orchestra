# Hypothesis Generation (Embedded)

**Source:** `hypothesis-generation` v1.0 | **Snapshot:** 2026-06-06
**Pipeline usage:** S1 fallback (when scientific-brainstorming unavailable)

## Workflow
1. **Understand the Phenomenon** — Clarify core observation/question
2. **Conduct Literature Search** — Ground hypotheses in existing evidence
3. **Synthesize Existing Evidence** — Analyze and integrate findings
4. **Generate Candidate Hypotheses** — Formulate testable explanations
5. **Design Experiments** — Propose methods to test each hypothesis
6. **Consider Alternatives** — Explore competing explanations
7. **Make Predictions** — Formulate testable predictions

## Hypothesis Formulation Template
- **Observation:** What phenomenon needs explanation?
- **Hypothesis:** Proposed explanation (if-then format)
- **Prediction:** If hypothesis is true, we should observe X
- **Test:** How to test the prediction
- **Alternative:** What else could explain the observation?
