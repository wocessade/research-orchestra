## Purpose

Publication diagrams: neural architectures, system diagrams, pipelines, pathways, PRISMA flows.

## Rules

- Exact paper terminology only
- One visual style per manuscript
- No fake numeric results in schematics
- Prefer vector SVG/PDF; inspect generated text for glyph errors
- Optional TikZ fallback for precise labels
- Colorblind-safe palettes (Okabe–Ito)
