# Stage T6.5: 盲审准备 [Strategist]

**Gate:** QT6.5 (SOFT BLOCK)
**Goal:** Prepare anonymous thesis version for blind review by removing all personally identifiable information.
**Needs Composers:** none

## Decisions

### Axis 1: Conditional Activation
```
if degree == "master":
    → activate T6.5 blind review preparation
    → proceed with full checklist

elif degree == "bachelor":
    → SKIP T6.5 entirely
    → set skip_reason = "bachelor_no_blind_review"
    → proceed to T7

elif degree not specified:
    → ask user for degree level
    → branch on response
```

### Axis 2: User Override
```
if user states "My university does not require blind review" OR equivalent:
    → SKIP T6.5
    → set skip_reason = "user_override_no_requirement"
    → flag [BLIND-REVIEW-OVERRIDE] in record
    → proceed to T7
```

### Axis 3: Anonymization Scope
Identify and remove/replace the following categories:

1. **Author information**
   - Student name → replace with "***"
   - Student ID → remove entirely
   - Photo/portrait → remove

2. **Supervisor information**
   - Advisor name → replace with "***"
   - Advisor title → remove
   - Advisor department → remove

3. **Institutional identifiers**
   - University name → replace with "*** University" or "某高校"
   - Department/School name → replace with "***学院" or "某学院"
   - Lab/Research group name → replace with "***实验室"
   - Course names → replace with "***课程"

4. **Personal acknowledgments**
   - Acknowledgments section → remove names of individuals
       → replace "感谢XXX教授" with "感谢导师"
       → replace "感谢我的同学XXX" with "感谢我的同学"
   - Keep sentiment, remove specific names

5. **Publication list (if any)**
   - If student has published papers during candidacy:
       → check if paper authorship reveals identity
       → if so, obscure co-author names
       → keep paper title and venue

### Axis 4: Conditional Deanonymization
```
for each anonymization target:
    if removing/obscuring this information destroys critical context:
        → e.g., "as shown in our previous study (Zhang et al., 2023)"
        → replacing "Zhang et al." makes reference meaningless
        → flag [DEANON-CONFLICT: reference_meaning]

    if conflict detected:
        → CONSULT USER
        → present: specific item, anonymization plan, context impact
        → options:
            a) anonymize as planned (context partially lost)
            b) keep identifiable (risk review failure)
            c) rewrite reference to be self-contained
        → user chooses

    conflict thresholds:
        - Reference becomes uncitable → must consult
        - Methodology relies on named institution resource → must consult
        - Named dataset uniquely identifies author → must consult
```

### Axis 5: Output Format
```
output:
    - Original thesis → "thesis_original.docx/pdf"
    - Anonymized thesis → "thesis_anonymous.docx/pdf"

anonymized_document_requirements:
    - Cover page: all identifiers replaced
    - Header/footer: remove author name, university from headers
    - Filename: use thesis ID or generic name, not author name
    - Metadata: clear author field in document properties

report:
    - list of all changes made
    - [DEANON-CONFLICT] resolutions
    - items that could not be anonymized (with justification)
```

## Gate

### QT6.5 Gate Checklist
- [ ] Activation decision made (active/skipped)
- [ ] User override checked
- [ ] All author identifiers anonymized
- [ ] All institutional identifiers anonymized
- [ ] Acknowledgments de-identified
- [ ] Deanonymization conflicts resolved
- [ ] Anonymized document generated
- [ ] Change log documented

### Gate Failure Route
```
if conflicts remain unresolved:
    → SOFT BLOCK — user must resolve deanonymization conflicts
if document fails to generate:
    → retry with format conversion
    → if persistent: notify user, proceed with original document
    → flag [ANONYMIZATION-FAILED]
if skip activated:
    → no gate failure — proceed to next stage
```
