### Axis 2: Intensity Level
```
user_choice OR default:
    if user specifies intensity:
        → use user choice
    else:
        → default = "heavy"

levels:
    - light:      10-15% volume increase / 1-2 expansion agents
    - medium:    20-30% volume increase / 3-4 expansion agents
    - heavy:     40-50% volume increase / 5-6 expansion agents (DEFAULT)
    - ultra:     70-100% volume increase / 7-8 expansion agents

LLM layer coverage:
    - light:      no LLM pass
    - medium:     no LLM pass
    - heavy:      50% LLM coverage (half of expanded content passes through LLM)
    - ultra:      70% LLM coverage
```

### Axis 3: AIGC Target Mode vs Full-Document Mode
```
if meta.json contains "aigc_target_indices":
    mode = "target_mode"
    → only expand specified sections
    → 100% LLM coverage on target sections regardless of intensity
    → non-target sections: no changes
    
elif meta.json does NOT contain aigc_target_indices:
    mode = "full_document_mode"
    → expand entire document
    → LLM coverage: only heavy (50%) and ultra (70%)
    
target_indices format:
    aigc_target_indices: [chapter_index, section_index, ...]
    e.g., [3.1, 3.2, 4.1] → expand sections 3.1, 3.2, 4.1 only
```

### Axis 5: Tiered Fallback
```
agent_execution:
    for each agent in expansion_agents:
        try:
            agent.execute()
        catch agent_failure:
            single_agent_failure_count += 1

fallback_rules:
    if single_agent_failure_count == 1:
        → fall back: skip this agent, continue with remaining
        → flag [AGENT-SKIPPED: agent_role]
    
    if single_agent_failure_count / total_agents > 0.3:
        → STOP-AND-ASK
        → present: too many agents failing
        → options:
            a) retry with lower intensity
            b) continue with partial results
            c) abort T6.7
        → user decides

quality_interception:
    for each agent's output:
        if is_well_formed(output) == false for >20% of output:
            → reduce intensity by one level
            → retry
            → if still >20% → STOP-AND-ASK
```
