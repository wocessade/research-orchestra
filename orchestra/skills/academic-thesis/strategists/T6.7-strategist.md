# Stage T6.7: 按缺口扩写与复核 [Strategist]

**Gate:** QT6.7 (CONDITIONAL BLOCK)
**Goal:** Fill explicitly requested content gaps using actual evidence, then re-review the changed manuscript.

## Activation and Scope

Enter from T6 when the user requests expansion or confirms the proposed content additions. Keywords alone do not authorize changing the manuscript. Preserve existing intent and requested length; no default heavy expansion percentage or detector-score target.
Record the specific gaps, affected chapters, evidence needed and intended additions. Expand explanation, method detail or analysis only where the provided material supports it. New results/cases/citations require actual artifacts/sources. Do not repeat paragraphs to meet length or turn uncertainty into stronger claims.

## Execution

1. Preserve the pre-expansion manuscript version; record current manuscript_revision and expansion_status=in_progress in the existing pipeline state.
2. Fill agreed gaps. Update citation support bank, contribution map and latest claim ledger revisions for changed/new claims. New evidence starts pending until checked. Keep anti-defensive writing rules from static/core/do-dont.md.
3. Check current text against sources, figures, tables and cross-chapter numbers. List unavailable evidence as open issues; don't invent analysis.
4. Set expansion_status=awaiting_review and invalidate prior content-review and blind-review completion for this changed manuscript.
5. Return to T5 for the degree/discipline-appropriate review; pass current manuscript, change list and evidence. T6 then resolves the cumulative Critical/Major issues using the shared convergence protocol. T6 must not re-enter this expansion merely because the original keyword persists.
6. QT6.7 passes only after the post-expansion T5/T6 review is READY. Set expansion_status=reviewed and expansion_recheck_complete=true for the reviewed manuscript_revision. Any further substantive edit invalidates this completion.

## Route

`T6.7 → T5 → T6 → T6.5 (master) → T7 (when defense requested)`.
For bachelor, omit T6.5. For revision-only entry without requested defense, finish after READY (and master blind-review preparation where requested). If T6.5 had already run, repeat it on the changed version; its old completion cannot cover new prose.
At the review round limit, return unfinished work plus concrete unresolved items; do not bypass the gate. Retain the pre-expansion version as a selectable artifact without overwriting or deleting either version.

## QT6.7 Checklist

- [ ] User-requested gaps and evidence sources recorded
- [ ] Revised manuscript version and change list preserved
- [ ] New/changed claims, sources, figures and cross-references checked
- [ ] Post-expansion T5/T6 completed on that version; READY with no open Critical/Major
- [ ] expansion_status=reviewed and expansion_recheck_complete=true recorded for that version
- [ ] Master T6.5 scheduled on the reviewed version; defense only follows the validated route
