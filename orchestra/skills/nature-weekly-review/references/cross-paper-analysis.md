# Cross-Paper Analysis — 跨论文分析规则

本文件提供事实比较与讨论框架。模型提出的关联或批判标为待讨论建议；个人判断以用户已确认内容为准，生成阶段不得新增冒充用户的观点。

## 触发条件

仅当 `papers.length >= 2` 时执行跨论文分析。单篇论文跳过此步骤，HTML section 显示占位。

## 分析维度

### 1. 主题聚类 (Theme Clustering)

**输入**：所有论文的 `tags` 列表

**方法**：Agent 使用语义理解合并同义词，将论文分配到主题组。

规则：
- 共享 ≥ 2 个标签 → 归入同一主题组
- 共享 1 个标签 → 分析标签含义，语义相关的可合并（如"扩散模型"+"DDPM"）
- 无法归类的论文 → 标记为"独立主题"

输出格式：
```
主题1: "<主题名>" — N 篇
  - Paper A (标签: ...)
  - Paper B (标签: ...)
主题2: ...
独立主题:
  - Paper C (标签: ...)
```

### 2. 方法对比表 (Method Comparison)

**输入**：所有论文的 "方法" section

**输出**：Markdown 表格

```markdown
| 论文 | 方法/架构 | 训练策略 | 数据集 | 关键创新 |
|------|----------|---------|--------|---------|
| ...  | ...      | ...     | ...    | ...      |
```

规则：
- 从每篇论文的 "方法" section 提取 5 列信息
- 若某篇论文的方法 section 为占位符（待精读），该列填 `—` 并加 ⚠️ 标记
- 若方法 section 只有英文原文（未翻译），直接使用原文

### 3. 指标对比表 (Metrics Comparison)

**输入**：所有论文的 "关键发现" section

**输出**：Markdown 表格

```markdown
| 论文 | 主要指标 | 基准/基线 | 提升 | 备注 |
|------|---------|----------|------|------|
| ...  | ...     | ...      | ...  | ...  |
```

规则：
- 从 "关键发现" 中提取定量结果（数字、百分比、benchmark 名称）
- 仅包含有实际数字的论文，纯占位符论文跳过此行
- 不同论文的指标不同属正常现象 — 不强行对齐，如实记录

### 4. 局限综合 (Limitation Synthesis)

**输入**：所有论文的 "批判" section

**按类别汇总**：

| 类别 | 说明 |
|------|------|
| 代码/复现 | 代码未开源、实现细节缺失 |
| 数据/评估 | 数据集偏窄、benchmark 覆盖不足 |
| 泛化 | 未在多领域/多语言验证 |
| 规模 | 模型规模受限、训练资源要求高 |
| 理论 | 缺少理论证明/收敛保证 |
| 其他 | 论文自行提及的具体局限 |

输出格式：
```
**代码/复现**: Paper X (未开源), Paper Y (依赖私有数据集)
**数据/评估**: Paper Z (仅评测英文 benchmark)
...
```

规则：
- 占位符批判（`[待精读后补充]`）→ 归入"待评估"类别，不强行填充
- 如果所有论文的批判都是占位符 → 显示"本周论文尚未精读，批判待补充"
