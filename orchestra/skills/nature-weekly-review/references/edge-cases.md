# Edge Cases — 边界情况处理

## 1. 本周无论文

**触发**：扫描范围内 `glob` 返回 0 个 `.md` 文件

**处理**：
- 封面标题改为"本周无新文献推送"
- 统计卡片全部显示 `0` 或 `--`
- 图表数据设为空/零（Chart.js 支持空数据集）
- ③~⑧ section 显示统一占位："本周暂无文献推送记录"

## 2. 仅 1 篇论文

**触发**：`papers.length === 1`

**处理**：
- 所有 section 正常渲染
- ⑤ 跨论文对比：显示"本周仅收录 1 篇论文，跨论文对比暂不适用"
- ⑥ 主题聚类：标签频率图正常显示（单篇也有标签分布）

## 3. 无 A 类论文

**触发**：`A_count === 0`

**处理**：
- ④ section 标题改为"A类重点论文（本周无）"
- 卡片区域显示提示："本周论文无 A_核心主线 分类，最高分论文如下"
- 自动展示 top-3 高分论文（按 score 降序）

## 4. 待精读占位符

**触发**：section 内容为 `[待精读后补充]` 或 `-`（仅破折号）

**处理**：
- 卡片标题加 `⚠️ 待精读` badge（黄色圆角标签）
- 关键发现为空 → 显示"待精读后补充"
- 批判为空 → 编译所有占位符论文的"待批判"列表
- 不阻塞渲染，正常展示已有内容

检测函数：
```javascript
function isPlaceholder(text) {
  return !text || text === "-" || /^\[待/.test(text);
}
```

## 5. 学习日志/实践日志缺失

**触发**：可选数据源文件不存在

**处理**：静默跳过。文献内容是唯一必选项。学习和实践内容为可选增强。

## 6. 跨月/跨年周

**触发**：ISO 周跨月或跨年（如 2026-06-29 至 2026-07-05）

**处理**：
- ISO 周计算自然处理，无需特殊逻辑
- 日期范围显示如"06/29 — 07/05"
- 扫描时遍历所有可能日期目录

## 7. 超大周 (>30 篇)

**触发**：管道异常或合并多周

**处理**：
- 文献总表设 `max-height: 600px; overflow-y: auto`
- 标签频率图限制 Top 15
- 分数分布和分类分布正常渲染（聚合不受影响）
- ④ A类卡片限制最多显示 5 篇（按 score 降序），其余折叠为"展开更多"

## 8. YAML frontmatter 缺失或损坏

**触发**：`---` 块不存在或 YAML 解析失败

**处理**：
- 跳过该文件，不计入总数
- 在控制台日志中记录文件名（agent 输出，不写入 HTML）
- 不影响其他论文的渲染

## 9. 标签为空列表

**触发**：`tags: []`

**处理**：
- 该论文仍计入统计和表格
- ⑥ 主题聚类中不参与标签频率统计
- 论文卡片不显示标签行
